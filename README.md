# Supply Chain Analytics Dashboard (Power BI + SQL)

## Project Overview
This project presents an End-to-End Supply Chain Analytics Dashboard developed using Power BI, SQL, and Excel. The dashboard provides actionable insights into sales performance, inventory management, supplier efficiency, logistics operations, and product quality.

## Objectives
- Monitor overall business performance
- Analyze inventory and stock levels
- Evaluate supplier performance
- Track logistics and shipping efficiency
- Identify product quality issues
- Support data-driven decision making

## Tools & Technologies
- Power BI
- SQL
- Microsoft Excel
- DAX
- Data Modeling
